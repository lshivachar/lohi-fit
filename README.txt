IMPORTANT: First back up your existing repository files and any existing app data. Do not delete other existing files. If your current app stores workouts in a different localStorage format, V2 cannot automatically migrate them. V2 saves new entries under a separate localStorage key. If you need old logs migrated, provide the old app source/backup.

GitHub Android workflow: Open repository in Chrome > Add file > Upload files (or edit existing files) > Commit changes. Preserve exact filenames. Wait for Pages to deploy, then refresh the installed app. If the old version persists, close and reopen or refresh while online. Avoid clearing site data because that can delete local workout logs.

This is a PROVISIONAL six-day programme based on coach screenshots. User should review and approve final exercise choices before training. Sunday is complete rest. Wednesday/Friday etc are assigned in a draft alternating upper/lower split. Reverse lunges replace step-ups. Exercise demonstration links open YouTube searches and require internet.

VOICE: Browser speech synthesis; voice availability and reliability depend on device, Android browser, sound settings and screen-awake status. Keep the screen awake. Timer may not run reliably in background.

DATA: local browser storage only. Use Settings > Export JSON backup regularly. Imports merge V2 backups; old app data is not migrated automatically.

TIMING: 5-minute warm-up + seven exercises x (3x60s + 2x30s) + six exercise-change rests x60s + 5-minute cooldown = 5+28+6+5 = 44 minutes. A one-minute transition can be added manually for 45 minutes. Short mode reduces exercise duration to 30 seconds and total session time accordingly.

RECOVERY: This app is not medical clearance. Avoid resistance training while symptomatic and follow clinician advice.
